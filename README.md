## 🧠 What I'm into

| | Focus | What it means to me |
|---|---|---|
| 🔍 | **Reverse Engineering** | Static and dynamic analysis, recovering structures and logic from binaries with no source in sight |
| 🎮 | **Game Hacking** | Memory analysis, hooks, overlays and tooling for understanding and extending games |
| 🛡️ | **Anti-Cheat Research & Bypass** | How user-mode and kernel-mode anti-cheats detect things, and where those defenses can be defeated |
| ⚙️ | **Kernel Systems** | Windows internals, drivers, and everything that happens below user mode |
| 🔌 | **Verilog / FPGA** | Designing digital hardware from the RTL up |
| 💾 | **DMA** | PCIe DMA hardware and reading memory from outside the host OS |
